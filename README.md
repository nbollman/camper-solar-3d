# Camper solar 3D

KZ Sportsmen S280BHSS — two 1×3 ZNShine 440 W wings.

## Send this in SMS (iPhone)

https://cdn.jsdelivr.net/gh/nbollman/camper-solar-3d@main/s280bhss-solar.usdz

That file is served as `model/vnd.usdz+zip`, so Safari opens the native 3D viewer.
He taps the link, then drags with one finger.

Also attach the JPEGs from this repo (`iso.jpg`, `top.jpg`) so the pictures arrive even if he does not tap the link.

Repo: https://github.com/nbollman/camper-solar-3d

To turn on the HTML page at https://nbollman.github.io/camper-solar-3d/ :
Settings → Pages → Source → GitHub Actions, then re-run the Deploy Pages workflow.
